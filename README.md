### 'HOW TO WORK IT OUT THE BOX'

1. Install the required programs

Download and install:

VS Code – https://code.visualstudio.com

Git – https://git-scm.com

Node.js (includes npm) – https://nodejs.org
 (choose the LTS version)

2. Get the project from GitHub

Go to the project’s GitHub page.

Click the green “Code” button.

Make sure the HTTPS tab is selected.

Click Copy to copy the link.

3. Open VS Code and set up your folder

Open VS Code.

Go to Terminal → New Terminal.

Decide what folder on your computer you want the project in.

Copy that folder’s file path.

In the VS Code terminal, type:

cd <paste your folder path here>

4. Clone the project

In the VS Code terminal type:

git clone <paste the GitHub HTTPS link here> <project-name>


Example:

git clone https://github.com/user/repo.git myproject


Then move inside the project folder:

cd myproject

5. Install project files (npm install)

Inside the project folder, run:

npm install


This downloads everything the project needs.

6. Run the project

Try one of these (the project usually uses one):

npm start


or

npm run dev


Your browser will open at something like:
http://localhost:3000
 or http://localhost:5173

7. Edit donation limit in dashboard.js

Open dashboard.js in VS Code.

Look for the text “to find all donations just do”.

Find where it says something like .limit(5) or the number 5.

Change the 5 to whatever number you want.

Save the file.

8. Add background image in app.css

Open app.css.

Look for the line with background-image.

If it is commented out (looks like /* ... */), remove the /* and */.

Make sure the file background.png is in the same folder as required.

Save the file.
